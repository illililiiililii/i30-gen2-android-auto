# 하드웨어 요구사항 판정

판정 기준은 **순정 GD13MY 기기에서 신규 수신기를 실행**할 수 있는지다. 확인됨은 지정한 펌웨어 또는 기기에서 그 사실을 직접 관찰한 경우다. 아래 표에서 실물과 펌웨어 근거를 각각 명시한다.

| 평가 항목 | 판정 | 근거 및 부족한 자료 |
|---|---|---|
| CPU 명령어·성능 | 부분적으로 확인됨 | ARM/Thumb little-endian 32비트 PE ABI 및 OMAP3530/Cortex-A8 BSP. 실물 클럭, ARM/Thumb 확장 런타임 지원, 실제 복합 부하 CPU 여유는 미측정. |
| RAM 및 가용 메모리 | 부분적으로 확인됨 | CE ROMHDR 19 MiB 초기 범위 및 COPYentry 확인. 실장량, CE 보고 물리 메모리와 OEM 활성 상태의 가용량 미확인. |
| USB Host 지원 | 확인됨(펌웨어) | MUSB OTG/HCD, USBD와 MSC/USB Disk 경로가 존재한다. 다만 해당 실물 포트와 하네스의 실제 속도와 전원은 검증해야 한다. |
| Android Auto 연결 협상 | 확인되지 않음 | CE에 AOA 클라이언트 등록에 필요한 계층은 보인다. PC 수신기는 실폰 AOA·bulk·버전 응답까지 확인했다. 공식 PC DHU는 같은 폰으로 TLS·영상·터치까지 확인했다. 순정 CE의 전송·인증은 실물 벤치 검증이 필요하다. [PC 시험](USB_CONNECTION_TEST.md) |
| H.264 영상 디코딩 | 부분적으로 확인됨 | TS 기반 순정 H.264 경로, `VID1:`, `videodev.dll`의 H.264 분기와 `DSP1:` 연결 근거. Android Auto 스트림 적합성과 지속 fps는 미확인. |
| 그래픽 출력 | 부분적으로 확인됨 | CE DDI/DirectDraw 및 EGL/GLES, 800×480 RGB565 로고 확인. 물리 패널 사양, 표면 선택, 조합과 카메라 우선 전환은 미확인. |
| 오디오 출력 | 부분적으로 확인됨 | SAF7730 WaveDev, PCM 출력·믹서/음량 경로. 순정 기능과 동시에 사용할 수 있는 채널과 지연은 미확인. |
| 마이크 입력 | 부분적으로 확인됨 | waveIn import, 드라이버 입력 경로, 순정 ASR. 실제 마이크 배선, 획득과 공유 가능 여부 미확인. |
| 터치·버튼 입력 | 부분적으로 확인됨 | 터치 드라이버 및 터치 좌표 참조, MICOM MIM1/MIM2와 메시징 경로. 버튼 매핑, 이벤트 소유권, CE 프로젝션 창에 전달되는 동작은 미확인. |
| 커스텀 소프트웨어 실행 | 확인되지 않음 | 실행 ABI는 확인했지만 OEM이 허용하는 진단/테스트 앱 로딩, 권한과 실행 형식을 벤치에서 확인해야 한다. |
| 업데이트 및 복구 | 부분적으로 확인됨 | 공식 패키지, 내부 체크섬, ROM의 복구 실행 파일과 경로. 실물에서 복구가 성공하고 기기 사용권한을 충족하는지는 미확인. |
| 세 후보의 기본 빌드 그대로 CE에서 실행 | 요구사항 미충족 | 조사한 각 프로젝트의 빌드 및 전송/미디어 API가 순정 CE 6.0 ABI를 표적으로 제공하지 않는다. 이 판정은 해당 코드의 기본 빌드에 대한 것이다. |

필요한 실물 정보는 본체 라벨의 부품 번호·HW 리비전, 순정 SW 버전, 보드 SoC/RAM/저장장치 마킹, OEM USB 및 전원 하네스, 카메라·마이크·스피커 구성이다. 우선 OEM 공식 자료에서 지원되는 실행 및 복구 경로를 확인한다. [심층 분석](DEEP_REVERSE_ENGINEERING.md) · [USB](USB_ANALYSIS.md) · [영상·오디오·입력](VIDEO_AUDIO_ANALYSIS.md)
