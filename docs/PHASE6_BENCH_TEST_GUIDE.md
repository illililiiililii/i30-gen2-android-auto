# Phase 6 순정 헤드유닛 벤치 테스트

첫 작업은 **전원을 연결하기 전에 본체 라벨, 후면 커넥터와 보유 하네스를 확인하는 것**이다. 현대의 국내 목록에는 i30 2013 표준형 2세대와 `GD13MY.KOR.SOP.00.061`이 대응한다. 차량 연식과 소프트웨어 이름은 후보를 좁히는 데 쓰고, 탈거한 본체의 부품 번호·HW 리비전과 인쇄된 커넥터 식별자를 기준으로 전장 회로도를 대조한다. 프로젝트에는 해당 본체에서 확인한 전압·전류·핀 배치가 없다. [현대 국내 SW 목록](https://update.hyundai.com/KR/KO/updateNoticeView/GVgVE4) · [현대 GSW 정비 지침서 및 전장회로도](https://gsw.hyundai.com/common/policyPop.action?kind=user)

## 준비물

| 준비물 | 확인할 내용 |
|---|---|
| 순정 본체와 하네스 | 모델명·부품 번호·HW 리비전이 보이는 라벨, 후면 단자 사진과 해당 리비전용 OEM 하네스 또는 검증된 벤치 어댑터. 커넥터 면과 배선 면 도면의 방향, 커넥터 키, 핀 번호 표기를 대조한다. |
| 서비스 자료와 전원 | GSW 전장 회로도 또는 제조사·정비사의 해당 부품 자료에서 전원·GND·기동 조건·정격·보호값을 확인한다. 정격에 맞는 안정화 전원, 전류 제한과 보호 퓨즈가 있는 하네스, 멀티미터를 준비한다. 전압·전류·핀 번호는 확인한 문서와 실제 하네스 측정값으로 기록한다. 자료가 일치할 때까지 전원을 연결하지 않는다. |
| 순정 USB와 폰 | OEM USB 포트/허브 및 하네스, 업데이트 파일이 없는 USB 미디어와 작은 지원 오디오 파일, 데이터 케이블, Android 테스트폰. Android Auto 단계에서는 등록된 테스트 인증 자료를 준비한다. 첫 순정 부팅에는 USB 미디어를 연결하지 않는다. |
| 시간·로그 수집 | PC, 사진/영상 기록이나 스톱워치, 전원 표시값 기록, 문서화된 서비스 진단·디버그 장비. 직렬 포트와 전압 기준이 확인되기 전까지 외부 시리얼 어댑터를 단자에 연결하지 않는다. |
| 오디오·화면·입력 | 일체형 순정 화면과 버튼을 먼저 쓴다. 별도 부품이 필요한 HW 리비전에서는 호환 화면·입력 장치, 해당 회로에 맞는 스피커 또는 앰프·마이크·카메라·신호 하네스를 준비한다. 카메라와 경고 조건은 OEM이 지원하는 벤치 시험 방식에서만 재현한다. |
| 복구 준비 자료 | 현재 버전과 모델에 맞는 검증된 순정 패키지, 제조사가 지정한 서비스 절차·매체·장비, 복구 지원이 가능한 서비스처. 현대 공지는 i30 2013 표준형 2세대의 업데이트 서비스 종료와 문의처를 안내한다. 해당 본체에서 같은 버전 재설치와 무부팅 상태의 복구 지원 여부는 별도 확인 대상이다. [현대 공식 서비스 종료 안내](https://update.hyundai.com/KR/KO/updateNoticeView/bWj0vy) |

## 진행 순서와 중단 조건

| 순서 | 수행할 행동 | 예상 결과 | 중단 조건 |
|---|---|---|---|
| 1. 기기 식별 | 전원을 끈 채 라벨·부품 번호·HW 리비전, 후면 단자와 하네스를 사진으로 기록한다. GSW 도면으로 핀 번호, 전원·GND·기동 조건과 정격을 확인한다. 순정 부팅이 된 뒤 화면에서 현재 SW와 지도 버전을 확인한다. | 단자와 도면이 일치하고, 본체 식별자와 실제 SW를 대상 펌웨어 후보에 대응시킬 수 있다. | 부품 번호나 배선·정격이 불명확하거나 자료가 충돌하면 연결하지 않는다. 지원 모델·리비전이 다르면 진단 실행과 패키지 사용을 보류한다. |
| 2. 순정 기준선 | 확인된 하네스와 보호 설정으로 전원을 연결한다. 쓰기가 시작되지 않은 상태에서 1회 정상 부팅을 관찰한다. 기동부터 홈 화면까지 시간, 기동·유지 전류, 버튼과 터치, 라디오/오디오를 기록한다. 지원 형식의 일반 USB 파일만 연결해 인식과 제거를 확인한다. | 홈 화면과 각 순정 기능이 응답한다. 오디오와 USB 인식은 해당 벤치에 연결한 순정 주변장치에서 관찰된다. | 발열·냄새·연기, 정격 밖 전류, 보호 제한 반복, 화면 무응답 또는 부팅 루프가 있으면 전원과 연결 상태부터 확인하고 다음 단계로 넘어가지 않는다. 전기적 이상은 즉시 전원을 차단한다. |
| 3. 복구 경로 | 서비스처에 해당 부품 번호의 정상 업데이트, 같은 SW 재설치 및 무부팅 시 공식 복구 범위를 문의한다. 부팅 상태별로 필요한 진행 화면·장비·매체를 기록한다. 읽기 전용으로 복구 진입과 정상 복귀를 확인할 수 있는 공식 절차가 있을 때만 그 절차를 관찰한다. | 정상 업데이트와 장애 복구의 진입 조건을 각각 확인한다. APP·OS·MICOM·부트 영역 중 어느 범위를 실제로 되돌릴 수 있는지 근거와 함께 기록한다. | 복구 문서가 없거나 실제로 부팅 불가 상태를 되돌리는 경로가 확인되지 않으면 파일·펌웨어 변경을 시작하지 않는다. 정상 업데이트 화면과 프로젝트의 `AVNRecovery.exe`는 복구 보장 근거로 사용하지 않는다. |
| 4. 독립 진단 앱 | 제조사 또는 서비스처에서 승인된 사용자 모드 실행과 로그 회수 경로를 확인한 경우에만 `i30-ce-probe.exe`를 독립 앱으로 실행한다. 시작·종료 로그, 종료 코드와 순정 화면 복귀를 기록한다. 앱은 자기 파일의 `MZ`를 읽고, 힙과 스레드를 검사하고, 모의 링크에서 버전을 확인한다. | `i30 CE bench probe start` 후 `i30 CE bench probe passed`, 종료 코드 0과 순정 UI 정상 응답. | 정상 실행 경로를 확인하지 못했거나 로더·import 오류, 예외, 종료 실패 또는 순정 UI 이상이 있으면 로그만 보존한다. 시작 등록·인증·검증 경로에 변경을 가하지 않는다. [진단 PE](../build/ce-minimal/i30-ce-probe.exe) · [ABI](CE_SDK_RESEARCH.md) |
| 5. Android Auto | CE 수신기에 필요한 기능이 연결된 뒤 순정 USB 열거 → AOA와 분리 → 등록된 인증으로 TLS → 영상 → 오디오 → 마이크 → 실제 버튼 순서로 시험한다. 각 기능을 추가할 때 성공 여부, 본체 시간, 전화기·수신기 로그와 분리 뒤 반환 상태를 기록한다. | 인증된 세션이 성립하고, 영상·음성·입력이 단계별로 작동한다. 분리 후 화면·입력·음향이 순정 기준선으로 복귀한다. | USB 인식 불량, 인증 실패, 영상·오디오 오류, 마이크나 입력 자원 미반환 시 마지막으로 통과한 단계까지만 인정한다. 순정 동작을 훼손하는 임시 우회는 쓰지 않는다. |
| 6. OEM 우선권 | 정차 또는 OEM 승인 벤치에서 카메라·경고 화면·라디오를 순정 기준선과 같은 조건으로 확인한다. 프로젝션 활성, 전환 중, 연결 해제 및 수신기 장애 상태에서 선점과 정상 복귀 시간을 관찰한다. | 순정 카메라·경고가 먼저 표시되고 사용자 선택과 자원 반환이 기준선에서 악화되지 않는다. | 카메라·경고가 지연되거나 보이지 않음, 순정 오디오 자원 미반환, 버튼 오작동 시 프로젝션 시험을 중단한다. 벤치에서 필요한 신호를 재현할 수 없으면 해당 기능을 미검증으로 남긴다. |

업데이트가 실제로 쓰기 중인 경우에는 정상 장애의 대응 절차를 제조사 지침에 따른다. 단순 응답 지연 때문에 전원이나 저장장치를 제거하면 복구 범위가 달라질 수 있다. 본 가이드에서는 쓰기를 유발하는 복구 시험을 진행하지 않는다. [현대 일반 업데이트 전원·미디어 유의사항](https://update.hyundai.com/RU/KO/updateGuide/04)

기록 항목은 `본체 모델/부품 번호/HW·SW/지도 버전 · 회로도 출처 및 리비전 · 하네스 · 전원/전류 제한/퓨즈 근거 · 부팅 시간과 기준 기능 · 복구 문서/확인한 범위 · 로그 파일 · 통과/보류/중단 사유`다. 1단계를 시작할 때 가장 필요한 자료는 본체 라벨과 후면 커넥터 사진, 보유 하네스 식별 정보다.
