# 무료 AI 후속 조사

우선순위는 이 프로젝트 이름으로 발급받을 수 있는 평가용 Android Auto 헤드유닛 신원이다. Google, 공인 시험기관, 현대모비스 또는 Tier-1 공급사의 공식 공개 자료로 지원 대상, 프로그램 신청 자격, 연락 채널, 제공 자료와 사용 범위를 각각 확인한다. 문서 URL, 확인일, 해당 문단, 사실과 추정을 구분한 판단표를 제출한다. 공식 DHU의 PC 테스트 기능과 별도 헤드유닛에 등록 가능한 평가 신원을 구분한다.

후보별로 폰이 신뢰하는 RSA 클라이언트 인증서 체인, 표준 `Z` 유효기간, 프로젝트 관리 하의 대응 키, 폰의 서버 체인 검증 자료 제공 여부를 표로 정리한다. 접근 권한을 공개 자료로 확인할 수 없는 후보는 미확인으로 기록한다. 제출물에는 공식 경로, 자격, 예상 준비물과 확인한 정책만 포함한다.

권한 있는 개발 신원 확보 뒤 Codex는 현재 ARM 빌드로 동일 폰의 USB AOA, AAP 1.7, 실제 송신 리프 지문, CertificateVerify, 상호 TLS Finished, `AUTH_COMPLETE`, 암호화된 서비스 탐색을 다시 시험한다. 각 단계를 UART와 폰 로그로 대응시키고, 인증 성공 후 첫 800×480 프레임, 터치, USB 분리·재연결을 확인한다. [과거 실패 근거](RESEARCH_VALIDATION.md)
