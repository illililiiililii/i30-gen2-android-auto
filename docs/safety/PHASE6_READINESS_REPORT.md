# Phase 6 준비 상태

**현재 진행 가능 범위는 헤드유닛 식별과 실물 벤치 준비다. 펌웨어 수정과 설치는 보류한다.** 탈거 본체의 부품 번호·HW 리비전·전원과 핀 배치·현재 SW, 본체에서 검증된 복구 경로가 아직 없다.

| 판단 항목 | 상태 |
|---|---|
| 순정 OS 이미지 | 프로젝트에 GD13MY CE 6.0 BIN이 있다. CE 커널 초기 진입을 두 EVM 모델에서 관찰했다. |
| 전체 부팅 및 실제 CE 실행 | 평가보드의 RAM 맵과 순정 커널 초기화 주소가 달라 셸, 실제 CE 로더와 API까지 도달하지 못했다. 동일한 지점의 추가 우회는 비용 대비 검증 가치가 낮아 보류했다. |
| ARMV4I 진단 앱 | 기존 PE를 이용해 정상 경로와 파일·스레드 오류 경로를 ARM 명령어 에뮬레이션으로 검증했다. 실물에서는 승인된 정상 실행 경로를 먼저 확인해야 한다. |
| 수신기 및 PC 검증 | 기존 PC 수신기에서 짧은 영상·오디오 동시 처리, 마이크 ACK·USB 재연결·오디오 경합·프로세스 복구를 확인했다. CE 포팅은 버전 협상까지이며, CE TLS·서비스 탐색, 실물 USB·영상·음향·물리 버튼과 OEM 우선권은 남아 있다. |
| 안전 및 복구 | 원본 순정 파일과 해시는 보유하고 있다. 승인된 실행 경로와 무부팅 상태에서 성공한 복구 근거가 없다. 소프트·하드 브릭 확률은 정량 추정할 수 없다. |

본체를 준비할 때 전원을 연결하기 전에 라벨의 부품 번호·HW 리비전, 후면 커넥터 사진, 사용 가능한 순정 하네스 정보를 확보한다. 그 정보로 회로도와 전원 보호 조건을 대조한 뒤 순정 부팅과 기능 기준선을 기록할 수 있다. 독립 진단 앱은 승인된 실행 경로가 확인된 뒤 사용한다. 실제 펌웨어 변경은 동일 리비전에서 정상 부팅으로 되돌릴 수 있는 복구 과정과 적용 대상 영역이 입증된 뒤에 다시 판단한다.
