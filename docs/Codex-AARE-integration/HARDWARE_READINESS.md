# GD13MY .061 실기 적용 점검

현재 통합 이미지는 에뮬레이터용 DiskA다. 원본 지도 파티션은 호스트에서 별도로 읽고, TLS 인증서 시간을 맞추기 위해 에뮬레이터 UTC를 전달한다. 패키징 도구도 AARE 신원 설정에 이 구성을 요구한다. 생산 업데이트 패키지, 부트로더 검증, 실제 장치 복구는 이번에 검증되지 않았다.

| 항목 | 점검 결과 |
| --- | --- |
| WinCE 코드 | .061 ARM 실행 파일과 DLL에서 BearSSL 상호 인증, AAP, H.264 디코딩과 GDI 표시를 수행한다. 삼성 실폰과 통신하는 시험에서는 PC가 USB 데이터만 전달했다. |
| USB 호스트 드라이버 | 삼성 폰의 TLS 마지막 74바이트를 처리한 변경은 `tools/gd13my_hcd_compat.py`에서 Unicorn의 stock `musbhcd.dll` 완료 분기를 보정한다. 현재 DiskA는 실기용 MUSB 드라이버를 포함하지 않는다. 실제 호스트 컨트롤러에서 동일 전송의 완료 길이 및 알림을 확인해야 한다. |
| 시간 및 인증서 | 시험 이미지는 에뮬레이터 UTC를 사용한다. 실기는 RTC와 유효기간을 확인하고 기존 P12와 수신기 승인 정보를 보존해야 한다. |
| 표시와 터치 | 에뮬레이터에서 실폰의 800×480 영상과 터치에 의한 앱 목록 전환을 확인했다. 실기 영상 속도, 장시간 연결, 후진 표시 선점과 복귀에는 실기 검증이 남았다. |
| 자동 연결 | 기존 시작 옵션은 USB 감지와 버전 요청을 수행한다. 영상까지 시작하려면 현재 빌드에서는 순정 메뉴에서 AARE 투사 창을 연다. 케이블 연결만으로 투사 창을 열려면 감지와 투사 창의 수명주기를 같은 USB 세션에서 이어야 한다. Android에서 요구하는 최초 USB 접근 및 인증서 승인은 남는다. |

현재 결과는 에뮬레이터와 실제 삼성 폰의 조합에서 확인한 값이다. 실기 적용 여부는 해당 .061 본체의 USB, RTC, 터치와 디스플레이 확인, 업데이트 전 원본 복구 검증에 달려 있다. [실폰 시험](REAL_PHONE_TEST_RESULTS.md)
